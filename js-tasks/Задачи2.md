## Правила для всех задач

1. Нельзя использовать встроенные методы массивов/строк.
2. Нельзя использовать `length`.
3. Нельзя использовать `for...of` и `for...in`.
4. Разрешены:

   * `for`
   * `while`
   * `if / else`
   * переменные
   * обычные операции сравнения и арифметики.
5. Если задача требует узнать размер массива или строки — его нужно получить **через цикл**.
6. `console.log` разрешён.
7. В задачах с массивами нельзя использовать `push`, `pop`, `slice`, `splice`, `filter`, `map`, `reduce`, `includes`, `indexOf` и т. п.

# Уровень 1 — понять сам принцип цикла

### 1. Посчитать символы

Дана строка:

```js
const word = "программирование";
```

Посчитать количество символов в строке, **не используя `length`**.

---

### 2. Вывести символы

Дана строка:

```js
const word = "hello";
```

Вывести каждый символ отдельной строкой:

```text
h
e
l
l
o
```

Нельзя использовать `split`.

---

### 3. Посчитать определённый символ

Дана строка:

```js
const word = "abracadabra";
const target = "a";
```

Посчитать, сколько раз символ `target` встречается в строке.

Ожидаемый результат:

```text
5
```

---

### 4. Развернуть строку

Дана строка:

```js
const word = "hello";
```

Получить:

```text
"olleh"
```

Нельзя использовать `reverse`.

---

### 5. Палиндром

Дана строка:

```js
const word = "комок";
```

Определить, читается ли она одинаково слева направо и справа налево.

Результат:

```text
true
```

Проверить также:

```text
"привет" → false
"шалаш" → true
"топот" → true
```

# Уровень 3 — массивы

### 11. Посчитать размер массива

Дан массив:

```js
const numbers = [10, 20, 30, 40, 50];
```

Получить количество элементов, **не используя `length`**.

То есть программа должна сама определить:

```text
5
```

Это специально важная задача: здесь человек должен понять, что массив — это последовательность элементов с индексами.

---

### 12. Вывести массив

Дан массив:

```js
const numbers = [10, 20, 30, 40, 50];
```

Вывести:

```text
10
20
30
40
50
```

Использовать цикл и индексы.

---

### 13. Сумма массива

Дан массив:

```js
const numbers = [10, 5, 8, 20, 3];
```

Посчитать сумму всех элементов.

Результат:

```text
46
```

# Уровень 4 — уже нужно понимать алгоритм

### 16. Фильтрация через функцию

Дан массив:

```js
const numbers = [1, 2, 3, 4, 5, 6];
```

И функция:

```js
function check(number) {
    return number % 2 === 0;
}
```

Получить новый массив, содержащий элементы, для которых `check` возвращает `true`.

Результат:

```js
[2, 4, 6]
```

Нельзя использовать `filter`.

---

### 17. Удалить дубликаты

Дан массив:

```js
const numbers = [1, 2, 3, 2, 4, 1, 5, 3];
```

Получить:

```js
[1, 2, 3, 4, 5]
```

Порядок первого появления должен сохраниться.

Нельзя использовать `Set`, `includes`, `indexOf`.

**Подсказка:** скорее всего, понадобится цикл внутри цикла.

---

### 18. Найти второй максимум

Дан массив:

```js
const numbers = [10, 5, 80, 20, 80, 45, 30];
```

Найти **второе по величине различное число**.

Результат:

```text
45
```

Для:

```js
[10, 80, 20, 80, 45]
```

результат тоже:

```text
45
```

То есть два `80` не должны считаться первым и вторым максимумом.

# Уровень 5 — комбинация нескольких концепций

### 19. Самое длинное слово

Дана строка:

```js
const text = "Я изучаю программирование на JavaScript";
```

Найти самое длинное слово.

Результат:

```text
"программирование"
```

Ограничения:

* нельзя использовать `split`;
* нельзя использовать `length`;
* нельзя использовать встроенные методы строк;
* нужно самостоятельно пройти строку символ за символом;
* пробел означает конец слова.

Здесь уже нужно одновременно понимать **состояние + цикл + условие**.

---

### 20. Группировка одинаковых элементов

Дан массив:

```js
const numbers = [
    1, 2, 1, 3, 2, 1, 4, 3, 2, 2
];
```

Получить объект с количеством каждого элемента:

```js
{
    1: 3,
    2: 4,
    3: 2,
    4: 1
}
```

Ограничения:

* нельзя использовать `Map`;
* нельзя использовать `Set`;
* нельзя использовать `reduce`;
* нельзя использовать `includes`;
* нельзя использовать `indexOf`;
* только циклы, индексы, условия и обычные операции с объектом.
